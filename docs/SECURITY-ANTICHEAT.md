# 🔒 حماية اللعبة من الغش — الحلول المنفذة والدليل

## 1) قواعد Firestore المشددة (`firestore.rules`) — منفذ ✅

قواعد سابقة كانت تسمح بأي كتابة؛ القواعد الجديدة تفرض:

### لوحة الصدارة (leaderboard) — الأهم
- **صيغة حساب النقاط مُعاد التحقق منها على الخادم**: النتيجة يجب أن تساوي
  `timeSurvived×12 + kills×25 + level×75 + (victory?8000:0)` — أي تلاعب
  بـ `score` من console المتصفح سيُرفض تلقائياً.
- **حدود منطقية**: زمن ≤ 7200 ثانية، قتلات ≤ 50000، مستوى ≤ 500، score ≤ 500000،
  وتاريخ سجل حقيقي (لا أكثر من 30 يوماً).
- **النتيجة لا تنزل أبداً**: `update` يرفض أي قيمة أقل من المخزنة.
- لا يُسمح بالحذف نهائياً.

### الحسابات (users)
- الكتابة فقط على مستند صاحبها (`auth.uid == userId`) + تحقق من الحقول
  (اسم ≤ 64 حرف، rankScore ضمن 500000…).

### التواجد (lobby / runLobby)
- كل لاعب يكتب مستنده فقط، وأماكن مقيدة (x/y ضمن نطاق معقول).

### الأصدقاء والفرق
- تحديث حالة الصداقة لا يستطيع تغيير سوى حقل `status` بقيمة مسموحة.
- تحديث الفريق محصور بحقول بيضاء (`members, hostId, matchStartedAt, matchDifficulty`)
  مع حد 4 أعضاء ورمز فريق صالح.

### رفض افتراضي شامل
- أي مجموعة غير مذكورة: `allow read, write: if false`.

## 2) كيف تنشر القواعد؟ (يتطلب تسجيل دخول مرة واحدة)

```powershell
# من مجلد المشروع
npx firebase login
npx firebase deploy --only firestore:rules
```

> `firebase.json` يشير أصلاً إلى `firestore.rules` وقاعدة البيانات الصحيحة.

قبل النشر يُستحسن تجربتها محلياً:
```powershell
npx firebase emulators:start --only firestore
# ثم: npx firebase firestore:rules:... أو مجرد تجربة اللعبة على المنفذ 8080
```

## 3) Firebase App Check (مجاني) — خطوات التفعيل يدوياً

يمنع السكربتات والأدوات الخارجية من مناداة قاعدة البيانات مباشرة:

1. افتح Firebase Console → **App Check** → سجّل تطبيق الويب.
2. أنشئ مفتاح **reCAPTCHA Enterprise** (الخطة القياسية مجانية حتى 1M تحقق/شهر)
   أو **reCAPTCHA v3**.
3. ضع المفتاح في `firebase-applet-config.json` داخل حقل `recaptchaSiteKey`.
4. ثبّت في الكود (مكتبة firebase موجودة أصلاً):
   ```ts
   import { initializeAppCheck, ReCaptchaV3Provider } from 'firebase/app-check';
   initializeAppCheck(firebaseApp, {
     provider: new ReCaptchaV3Provider('<SITE_KEY>'),
     isTokenAutoRefreshEnabled: true,
   });
   ```
5. في Console → App Check → فعّل **Enforcement** على Firestore (ابدأ بوضع
   Monitor أولاً لمدة أسبوع للتأكد من عدم كسر أي شيء، ثم Enforce).

## 4) ما تبقى من مخاطر (يتطلب خادماً — خارج نطاق الحلول المجانية)

- الغش **داخل اللعبة نفسها** (تعديل متغيرات المحرك من DevTools) لا يمكن منعه
  من الخادم إلا بـ Cloud Functions تحسب النتيجة من تيار أحداث مُرسل — وهذا
  مدفوع/معقد.
- الحل المنفذ يجعل أي نتيجة مزيفة على لوحة الصدارة **مستحيلة رياضياً** ما لم
  يلعب اللاعب جولة حقيقية طويلة كفاية — لأن الخادم يعيد حسابها بنفس الصيغة.

## 5) ملخص الاستجابة للأنظمة (متصل/غير متصل)

- نظام عدم الاتصال (الجلسة السابقة) لم يغيّر الأمان: القواعد تُفحص على الخادم
  عند كل مزامنة، فالتزامن المتأخر مرّ بنفس التحققات.
